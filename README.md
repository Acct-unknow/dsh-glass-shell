# 毛玻璃外壳（dsh-glass-shell）

把 DeepSeek Harness 的外壳换成磨砂玻璃：侧边栏、输入卡、消息气泡、卡片、菜单与弹层都变成半透明玻璃，背景可以是当前主题、一种纯色，自己选择的渐变，或者你自己上传的一张图片。

## 它做了什么

| 表面 | 做法 |
| --- | --- |
| 整个应用的背景 | 一个 `position: fixed; z-index: -1` 的背景层（`#dsh-glass-shell-wall`），画纯色 / 图片 / 主题渐变，并在这层上做 `filter: blur()` |
| 侧边栏、中间列 | 各自只画一层半透明底色，露出后面的虚化背景 |
| 输入卡 | 半透明底色 + 真正的 `backdrop-filter`，对话文字从下面滚过时会被糊掉 |
| 消息气泡 / 代码块 / 卡片 / 菜单 / 弹层 | 覆盖对应的 `--dsw-alias-*`、`--dsw-specific-*` 主题 token 为半透明色 |
| 明暗主题 | 两套 token 都会覆盖（`body[data-ds-dark-theme]`），切换主题不需要改设置 |

## 设置项

设置 → **毛玻璃**：

- **启用毛玻璃**：总开关；
- **背景虚化**：0–48px；
- **面板透明度**：0–100%，越高玻璃越透（拉到 100% 时面板不再画底色，只剩背景和折射边缘）；
- **折射玻璃模式**：开关 + 折射强度 0–100%。打开后面板不再靠半透明底色假装磨砂，而是用 SVG 位移滤镜把身后的像素真正掰弯（法线贴图是一张程序生成的小 PNG，中心不位移、四边与圆角处把背景往里挤）。强度按像素算，模糊也在滤镜里完成，所以面板无论大小、宽高比都不会拉伸变形；关掉开关即回到原来的做法。
- **背景饱和度**：80–220%；
- **直接选个颜色**：一排常用色块（深蓝/石墨/墨绿/紫罗兰/暖陶/雾蓝/米白/樱粉），点一下背景就是这个纯色 —— 会自动切到「纯色」并启用毛玻璃；
  旁边还有一个取色器（任意颜色）和一个 `#rrggbb` 输入框，回车即应用；
- **屏幕取色**：按钮会调用浏览器的 EyeDropper（Chromium 95+ 提供，在 DSH 桌面版里是**系统级吸管**），点一下屏幕任意位置就能取色，包括别的窗口里的像素；按 Esc 取消。内核没提供这个接口时按钮会给一句提示，不会静默失败。渐变的起始色、结束色下面也各有一个自己的「屏幕取色」，只改那一边的颜色；
- **我的渐变**：把当前的两色 + 方向整组存下来（最多 12 组）。默认折叠成一个标题条（带数量、带一个 `›` 箭头），点标题条就展开，竖着一条条列出来：34×34 渐变大色块 + 色号 `#a → #b` + 方向名，点色块整套恢复；悬停右上角 × 删除。渐变的两支颜色下面还各挂了一排「常用色」小块，点一下只把这一边设成那个颜色；
- **最近使用 / 我的常用**：取过的颜色自动进「最近使用」（去重，最多 14 个）；「存当前色」把现在的颜色收进「我的常用」（最多 24 个）。两组都默认折叠（原生 `<details>`，点标题条就展开，不依赖 JS 状态）后竖着列出来：34×34 大色块 + 色号，右侧 × 删掉「我的常用」里的某一条。色块尺寸写在 inline style 里（34×34 + `flex:0 0 auto`），不管外部布局怎么挤都不会再变成一条细线。渐变模式下右边多一个「纯色 / 起始 / 结束」开关，决定色块改的是哪一个颜色；
- **背景来源**：跟随主题 / 纯色 / 渐变 / 图片（图片可设填充方式与暗化程度）；
- **渐变**：两种颜色各自取色（默认黄 → 紫），每个颜色旁边还能直接输入 `#rrggbb` 色号（回车或失焦生效，写错会退回原值）；右边 3×3 方向键盘选渐变方向（左上→右下、左→右等 8 个方向），下面一条实时预览带；纯色模式的设置完全不受影响；
- **恢复默认**。

设置即时生效并保存在本机 `localStorage`（键 `dsh-glass-shell.settings.v1`，图片单独存在 `dsh-glass-shell.image.v1`，取色历史/常用色存在 `dsh-glass-shell.palette.v1`）。上传的图片会在浏览器里压缩到最长边 ≤ 2200px、WebP 质量 0.86，并压到 1.6MB 字符以内再存。

## 安装

这个仓库的根目录就是插件目录本身：它通过 `link:` 装进 DSH profile，**改完文件刷新页面即生效**，不用重装。

- 本机已装好，改代码 → 刷新页面即可；
- 换一台机器：把整个仓库目录拷过去，在 DSH 的 **设置 → 插件 → 添加本地插件** 里指向它（或 `dsh plugin --profile <profile> add <绝对路径>`）。
- 从 GitHub 装：`git clone https://github.com/Acct-unknow/dsh-glass-shell.git glass-shell`，然后在 DSH 的 **设置 → 插件 → 添加本地插件** 里选这个目录。改完代码 `git pull` 再刷新页面即可。

## 配置跟着插件目录走

设置页里调的所有东西（背景、渐变、色板、图片）除了存在浏览器里，还会**镜像到插件目录的 `store.json`**：

- host 半端 `index.js` 注册了 `/dsh-glass-shell/store.json` 路由：`GET` 读快照、`POST` 写快照（先写 `.tmp` 再 `rename`，不会写一半）；
- 每次改设置、换图片、存颜色/渐变色板，约 0.8 秒后自动写一次 `store.json`；
- 新机器装上这个插件时，如果目录里带着 `store.json`，页面启动会把它读进来覆盖本机空配置 —— 整目录拷过去就带着当前这套配置；
- 谁更新用 `savedAt` 时间戳判断（浏览器那边记在 `dsh-glass-shell.store.v1`）；
- 路由不存在（没装 host 半端 / 还没重启）时客户端安静退回纯本地存储，不影响使用。

注意：host 半端改动要**重启 DSH** 才生效；只改 `client.js` 刷新页面即可。

## 打包分发

平时不留压缩包（容易变成过期副本）。要搬到别的机器时再生成：

```bash
python tools/pack.py
```

输出 `dist/dsh-glass-shell-<version>.zip`（zip 里包着一层 `glass-shell/`），解压后得到一个可直接安装的插件目录。版本号取自 `package.json`。

`store.json` 会被一起打进去（那正是「带配置换机」的用法）；它本身在 `.gitignore` 里，不会被提交到仓库。

## 仓库结构

```
package.json        DSH bundle 清单（dsh.bundle.patch / dsh.client / files）
cordis.patch.yml    插入插件条目
index.js            host 半端：/dsh-glass-shell/store.json 读写路由
client.js           客户端半端：注入样式、背景层、折射滤镜、设置页
icon.svg            插件图标
docs/DETAIL.md      实现细节（滤镜管线、token 覆盖、同步机制）
tools/pack.py       按需打 zip
```

`client.js` 是唯一需要改的大文件；`index.js` 改动要**重启 DSH** 才生效。

## 已知限制

- 背景层依赖 `body` 背景透明；如果别的皮肤插件也把 `body` 背景改成不透明，两者会打架 —— 同一时间只启用一个皮肤插件。
- 面板玻璃是在「外壳骨架」层做的（列级），列内部如果某个页面自己画了不透明底色，那块区域就不会透。
- 图片存在浏览器本地存储里：换浏览器 / 清站点数据后就没了。
- `store.json` 是一份快照，两台机器同时改会互相覆盖（后保存的那次赢）。
- 折射玻璃模式用的 SVG 位移滤镜走 `backdrop-filter: url(#...)`，需要 Chromium 内核支持；不支持时自动退回普通模糊。
